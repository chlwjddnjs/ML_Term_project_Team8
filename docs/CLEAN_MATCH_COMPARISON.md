# 오매칭 제외 전후 교차 데이터셋 평가

2026-11-05 실행. 팀원 검토 라벨의 `different`와 `unsure` 연결을 제외하고, 동일한 모델 점수로 전문가 순위 비교를 다시 계산했다. 추천 모델 설정은 변경하지 않았다.

## 재현과 저장 위치

```bash
python experiments/compare_clean_matches.py
```

결과는 `outputs/clean_matches/`에 저장된다. 기존 `outputs/cross_dataset.csv`는 덮어쓰지 않는다. `run.py`의 기본 매칭 방식도 변경하지 않았으므로 정제 결과 재현에는 위 명령을 사용한다.

- `comparison.csv`, `deltas.csv`: 정책별 및 공통 와인 집합의 결과·차이
- `cross_dataset_before.csv`, `cross_dataset_after.csv`: 제외 전후 주요 비교표
- `match_counts.csv`, `matches_before.csv`, `matches_after.csv`: 연결 수와 연결 목록
- `match_audit.csv`, `removed_matches.csv`: 각 연결의 라벨·판정 이유·처리 내역
- `previous_cross_dataset.csv`: 기존 실행 결과 백업 (첫 실행에만 생성)
- `settings.json`: 실행 설정과 제외 정책

## 비교 방법

기존 파이프라인과 같은 Slim 데이터·정제·seed 42·사용자별 분할·linear 점수 변환을 사용했다. 저장된 학습 모델이 없으므로 동일 설정으로 각 모델을 한 번 학습하고, 계산한 와인별 대표 점수를 제외 전후에 재사용했다. 전문가 점수와의 상관이 높아지는 방향으로 라벨이나 파라미터를 선택하지 않았다.

정규화 exact 연결은 유지하고, fuzzy-only 연결은 `same` 라벨만 유지했다. `different`와 `unsure`는 제외했다. 누락 라벨 및 중복 라벨 키는 오류로 처리해 조용히 통과하지 않게 했다. 검토 키는 X-Wines item_id와 전문가 와이너리·와인명으로, 같은 검토 쌍에 속하는 리뷰들에 동일한 판정을 적용한다.

## 결과

와인 169개·리뷰 연결 415건에서 와인 163개·리뷰 연결 396건으로 줄었다. fuzzy-only 검토 쌍 15개(다른 와인 12개, 불확실 3개)에 해당하는 리뷰 연결 19건을 제외했다.

| 모델/기준 | 제외 전 Spearman (169개) | 제외 후 Spearman (163개) | Top-10 겹침 전 → 후 |
|---|---:|---:|---:|
| 사용자 평균 평점 | 0.705818 | 0.683429 | 0.6 → 0.6 |
| Popularity | -0.002734 | -0.007749 | 0.0 → 0.0 |
| ItemKNN | 0.648016 | 0.621820 | 0.4 → 0.4 |
| MF | 0.698550 | 0.675219 | 0.5 → 0.5 |
| Content | 0.325989 | 0.344296 | 0.3 → 0.3 |
| Hybrid | 0.709090 | 0.690305 | 0.5 → 0.5 |

대상 와인 감소 효과를 구분하기 위해 공통으로 남는 163개만으로도 비교했다. 같은 163개에서 Hybrid 상관은 0.704361 → 0.690305, Content는 0.343379 → 0.344296이었다. 따라서 전체 수치 변화에는 와인 집합 변경과 남은 와인의 전문가 평균 평점 변경이 함께 작용한다.

## 해석과 한계

확인된 오매칭을 제외했지만 상관계수가 모두 높아지지는 않았다. 데이터 정제의 목적은 상관을 높이는 것이 아니라 잘못된 비교 대상을 줄이는 것이다. Hybrid는 정제 후에도 전문가 평가와 양의 순위 관계를 보였고, Top-10 중 5개가 겹쳤다. Content의 상관은 조금 상승했지만 모델 간 개선이나 우월성의 통계적 검정은 하지 않았다.

이 작업은 전문가 외부 검증만 바꾼다. X-Wines 내부 추천 지표(P@10, Recall, NDCG)나 모델 학습 성능이 개선됐다는 의미는 아니다. 최종 외부 검증 보고에는 정제 후 163개 결과와 제외 기준을 사용하고 기존 169개 결과는 비교 실험으로 남기는 것이 적절하다.

검토 라벨은 팀원의 판정이며, 유지한 `same`과 exact 연결까지 독립적으로 정답임을 보장하지 않는다. 빈티지 차이와 제한된 겹침 범위 등 기존 한계도 남는다.
